01 / FUNDAMENTOS · 2 MIN

Antes de preguntar, entendamos cómo funciona.

Un LLM (Large Language Model) es un modelo entrenado para procesar y generar lenguaje. Claude y los modelos GPT son ejemplos de esta tecnología.

¿QUÉ ES UN TOKEN?

El modelo divide el texto en unidades pequeñas llamadas tokens (palabras, partes de palabras o signos).

Ventana de contexto

01 / MODELOS · 2 MIN

No todas las tareas necesitan el mismo modelo.

Elige según el tipo de razonamiento y el trabajo que necesitas hacer — no solo por el nombre del proveedor.

Menor esfuerzo · rápido

Haiku

OpenAI · línea rápida

Pensado para respuestas ágiles y tareas de una sola pasada.

En Filter: resumir correos, clasificar solicitudes, sacar datos puntuales.

Equilibrado

Sonnet

OpenAI · razonamiento medio

El trabajo cotidiano: analizar, comparar y redactar con contexto.

En Filter: comparar productos, revisar Excel, armar informes comerciales.

Mayor esfuerzo · profundo

Opus

OpenAI · razonamiento alto

Para problemas complejos con varios pasos y mucha información.

En Filter: conciliaciones difíciles, inconsistencias entre archivos, planificar integraciones.

Menor esfuerzo→Equilibrado→Mayor esfuerzo
Primero mejora el contexto y las instrucciones. Si la tarea sigue siendo difícil, sube el razonamiento o cambia de modelo.

Orientación general — no es una equivalencia exacta entre proveedores. Revisa siempre el resultado; más esfuerzo no siempre es mejor.

01 / PROMPTING

La forma en que preguntas cambia lo que recibes.

Claude puede responder a una pregunta sencilla, pero si necesitas un resultado específico, darle contexto e instrucciones claras marca la diferencia.

01 · Prompt básico

Útil para explorar ideas, hacer preguntas generales o comenzar una conversación.

Ejemplo
Recomiéndame un filtro hidráulico para un cliente.

Claude puede orientarte, pero todavía no conoce las condiciones del equipo, el catálogo disponible ni el resultado que esperas.

02 · Prompt estructurado

Más útil cuando necesitas resolver una tarea concreta con requisitos definidos.

Ejemplo
Objetivo

Ayúdame a identificar opciones de filtración hidráulica para responder una solicitud comercial.

Contexto

El cliente necesita un filtro para 40 L/min, 180 bar y filtración de 10 μm. Todavía no informó el tipo de conexión ni el material del sello.

Información disponible

Utiliza exclusivamente el catálogo de productos adjunto.

Tarea

Compara las alternativas documentadas, identifica las especificaciones faltantes y señala cuáles requieren validación técnica.

Formato

Entrega una tabla comparativa con código, caudal, presión, micraje, conexión y fuente. Finaliza con tres preguntas para el cliente.

Restricciones

No inventes productos, precios ni equivalencias. No confirmes compatibilidad definitiva sin la información necesaria.

Claude sabe qué analizar, con qué información trabajar, qué entregar y qué no debe asumir.

Los 5 elementos de un prompt claro

No todos los prompts necesitan obligatoriamente los cinco elementos. Las restricciones y los criterios de validación pueden incorporarse dentro de las instrucciones.

  1. 01ObjetivoQué necesitas conseguir.
  2. 02ContextoQué información debe conocer.
  3. 03InstruccionesQué debe hacer y qué debe considerar.
  4. 04EjemplosUna referencia del resultado esperado, cuando sea útil.
  5. 05FormatoCómo quieres recibir la respuesta.

No se trata de escribir prompts más largos, sino de dar la información necesaria para obtener el resultado que necesitas.
