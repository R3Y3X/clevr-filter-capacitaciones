# Guía para quien presenta — Clevr × Filter

**Duración objetivo:** 85 min (excluye preparación técnica previa). El HTML es la presentación, este archivo es el guion compacto.

| Fase | Min | Puntos a demostrar |
|---|---:|---|
| Ecosistema + caso | 5 | La IA no solo responde; contexto → método → conexión → ejecución |
| Projects | 12 | Crear proyecto, adjuntar catálogo, preguntar con fuentes; hands-on |
| Skills | 12 | Proyecto = qué sabe; Skill = cómo lo hace; importar Skill; hands-on |
| Conectores y MCP | 10 | Diagrama MCP; correo ficticio con o sin Gmail conectado |
| Investigación | 8 | Investigación con citas; iniciar antes si puede tardar |
| Design / Artifacts | 8 | Crear ficha de una página desde respuesta previa |
| Cowork / Claude Code | 12 | Tarea de conciliación CSV; distinguir tarea puntual y programada |
| Oportunidades Filter | 18 | 6 áreas, primeros pilotos, cierre con compromiso de una tarea por área |
| **Total** | **85** | |

## Antes de entrar
1. Abrir el HTML en Chrome/Edge; activar pantalla completa con F11 (y probar a 1366×768).
2. Tener el ZIP y los CSV extraídos localmente; dejar abierta la carpeta `kit`.
3. Ingresar a Claude; comprobar plan, Skills y Cowork; nunca prometer herramientas no habilitadas.
4. Crear opcionalmente un Project `Filter — DEMO` y subir `CATALOGO_FILTER_DEMO.csv`.
5. Si hay Gmail / Drive conectados, usar solo una cuenta de prueba y documentos ficticios.
6. Conectar proyector antes de empezar y probar copiar texto.

## Plan B sin Cowork ni integraciones
Todo se puede enseñar con chat + archivos adjuntos; presenta los conectores y automatizaciones conceptualmente sin simular acceso real. No mostrar claves ni datos privados.

## Validación de resultados
Comprobar FH-120 (teórico 3 vs reportado 4), registro duplicado FH-100 y los SKUs desconocidos XX-404 / XZ-999. La comparación de filtros NO debe asegurar equivalencia técnica.

## Nota sobre tareas programadas
Las tareas recurrentes de Cowork en versiones recientes de Claude pueden ejecutarse en la nube, pero ciertas tareas que dependen de recursos locales pueden requerir el dispositivo; confirmar la modalidad vigente y permisos. Documentación: https://support.claude.com/es/articles/13854387-programar-tareas-recurrentes-en-claude-cowork
