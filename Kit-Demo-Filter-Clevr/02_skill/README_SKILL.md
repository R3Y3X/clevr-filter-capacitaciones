# Cómo probar la Skill

1. En Claude, abre la sección de Skills (la ubicación exacta depende de la versión).
2. Si tu cuenta permite cargar Skills y tiene ejecución de código habilitada, importa el archivo ZIP `Skill-Analisis-Filtros.zip` incluido junto al material entregado.
3. En un Project con el catálogo ficticio, pide: «Usa la Skill de análisis preliminar de filtros para comparar 40 L/min, 180 bar y 10 µm; conexión y sello aún desconocidos».
4. Verifica que se señalen dudas técnicas y no se inventen códigos.

Alternativa: pega el contenido del `SKILL.md` como instrucciones en un chat si la cuenta no permite importar.

**No usar para decisiones técnicas reales.**
