# KIT DE DEMOSTRACIÓN · Clevr × Filter · Claude 101

**100 % ficticio**. Ningún producto, compañía, SKU, correo o dato es real. No emplear para decisiones de ingeniería o negocios.

**01_project:** instrucciones de Project, catálogo y solicitud de cliente de ejemplo.
**02_skill:** Skill en formato SKILL.md (también se entrega archivo ZIP importable).
**03_operaciones:** tres CSV para analizar, reglas, hallazgos que debe detectar Claude (para presentador).
**04_correos:** tres correos `.eml` simulados y guía para usarlos sin y con Gmail.
**05_gerencia:** prompts de investigación y Design/Artifacts.
**06_presentador:** guion, timings y plan B.

## Secuencia de prueba
1. Crear Project e incorporar catálogo y contexto.
2. Comparar requerimientos 40 L/min, 180 bar, 10 µm; revisar fuentes.
3. Importar o pegar la Skill y repetir.
4. Analizar las tres planillas CSV con Claude o Cowork.
5. Adjuntar los correos `.eml` o probar Gmail autorizado en buzón de pruebas.
6. Crear una ficha visual con los datos obtenidos.

**Límites:** no se crearon ni enviaron correos ni se subieron archivos a Drive desde esta preparación. Las conexiones a servicios reales se hacen manualmente y con autorización.
